# 꼭지제거 작업 규칙

작업대의 꼭지제거 작업 로직을 검토하거나 수정하기 전에 이 문서를 기준 규칙으로 확인한다.

## 1. 기본 개념

작업대의 꼭지제거 작업은 `꼭지만 제거`와 `꼭지 제거 + 부분선별` 두 가지다.

- 두 작업은 모두 `작업대에서만` 진행한다.
- 두 작업 모두 `처리 단위`는 `6박스`다.
- 실제 실행량은 투입 인원과 남은 노동시간 기준으로 가능한 만큼 `6박스 단위`로 반복 처리한다.
- `부분선별`은 `A급 / B급 / 가공품`까지만 나누고, `다이 선별`은 하지 않는다.
- `다이 선별`은 선별기에서만 처리한다.
- 잔량 박스도 `1박스`로 취급한다.
- 실제 작업 대상은 작업 시작 전에 사용자가 지정한 `투입칸`에 들어 있는 수확물 박스만 본다.
- `투입칸`과 `배출칸`은 작업대가 설치된 현재 창고의 수확물 적재칸 중에서 지정한다.
- 꼭지제거 작업은 작업대가 설치되어 있어야 진행할 수 있다.

## 2. 작업 모드

### 2-1. 꼭지만 제거

원물 상자의 꼭지만 제거해 다음 선별 단계로 넘길 수 있는 상태로 바꾸는 작업이다.

- 입력 대상은 `꼭지있음` 상태의 박스만 허용한다.
- 이미 `꼭지제거됨` 상태인 박스는 작업 대상에서 제외한다.
- 결과물은 `꼭지제거됨` 상태를 가진다.
- `급`은 `급 미정` 상태를 유지한다.
- `다이`도 `다이 미정` 상태를 유지한다.
- 결과물은 입력 박스의 과종, 품종, 품질명, 급, 수확일, 잔량 kg 정보를 유지한다.
- 박스 수, kg, 품질명, 급은 변하지 않고 꼭지 상태만 바뀐다.

### 2-2. 꼭지 제거 + 부분선별

꼭지를 제거하면서 동시에 `A급 / B급 / 가공품`까지 1차 분류하는 작업이다.

- 입력 대상은 `꼭지있음` 상태의 박스만 허용한다.
- 이미 `꼭지제거됨` 상태인 박스는 작업 대상에서 제외한다.
- 결과물은 `꼭지제거됨` 상태를 가진다.
- 결과물은 `A급`, `B급`, `가공품` 중 하나의 `급`을 가진다.
- `다이`는 아직 붙지 않으며 `다이 미정` 상태를 유지한다.
- 결과물은 입력 박스의 품종, 수확일, 잔량 kg 정보를 유지한다.
- 한 입력 박스는 `A급 / B급 / 가공품` 비율에 따라 여러 잔량 결과 박스로 쪼개질 수 있다.
- 서로 다른 품종의 수확물을 한 결과 박스에 섞어 담으면 안 된다.
- 과종, 품종, 품질명, 급, 다이, 꼭지 상태, 박스종류가 같은 잔량 상자끼리는 가능한 만큼 합쳐진다.
- 같은 조건의 잔량 상자끼리는 20kg 만박스를 만들 수 있으면 만들고, 남는 kg만 잔량 박스로 둔다.
- 예: 같은 조건의 7kg 잔량 상자와 13kg 잔량 상자는 20kg 1박스로 합친다.
- 예: 같은 조건의 7kg 잔량 상자와 8kg 잔량 상자는 15kg 잔량 1박스로 합친다.
- 새 결과 박스는 사용자가 지정한 `배출칸` 안에서만 배치한다.
- 결과 배치 순서와 잔량 합치기 판단도 선택된 `배출칸` 범위 안에서만 처리한다.
- 결과 박스 배치 순서는 `A급 -> B급 -> 가공품`을 기본으로 한다.
- 합치는 과정에서 박스 수가 줄면 줄어든 빈 상자는 현재 창고/토지의 일반 상자 재고로 돌아간다.
- 작업 시작 전 필요한 상자 수는 합친 뒤 최종 결과 박스 수 기준으로 계산한다.
- 합친 뒤 최종 결과 박스 수가 입력 박스 수보다 적으면 남는 빈 상자는 현재 창고/토지의 일반 상자 재고로 돌아간다.
- 부분선별 결과 kg 합계는 입력 박스 kg 합계와 같아야 한다.
- 부분선별로 결과 박스 수가 늘어날 수 있다.
- 꼭지 제거가 끝난 입력 박스의 빈 상자는 현재 창고/토지의 일반 상자 재고로 돌아간다.
- 결과 잔량 박스로 나눌 때 필요한 새 상자는 해당 창고/토지의 상자 재고에서 가져다 쓴다.
- 결과 잔량 박스에 필요한 상자가 부족하면 작업을 시작하면 안 된다.

## 3. 처리 기준

`꼭지 제거 + 부분선별`의 `A급 / B급 / 가공품` 분류 비율은 선별기 규칙과 같은 기준을 사용한다.

- 품질이 낮을수록 `가공품` 비율이 높아진다.
- 품질이 높을수록 `A급` 비율이 높아진다.
- `B급`은 중간 완충 구간 역할을 한다.

즉, 작업대 부분선별은 선별기의 품질 분류 규칙을 공유하되, `다이` 단계 전까지만 처리한다.

창고 적재칸 사용 규칙은 다음과 같다.

- 꼭지제거 작업은 이미 창고/토지 적재량 안에 들어온 수확물을 처리하므로, 별도 창고 kg 용량 증가로 보지 않는다.
- 꼭지제거 전후 총 kg는 같아야 하며, 작업 시작 판단은 선택된 `배출칸`에 결과 박스를 배치할 수 있는지 기준으로 한다.

## 4. 시간과 노동력

두 작업은 같은 시간이 아니다.

- `꼭지만 제거`가 더 짧다.
- `꼭지 제거 + 부분선별`이 더 오래 걸린다.
- `꼭지 제거 + 부분선별`이 노동력도 더 많이 든다.
- 두 작업 모두 작업자와 노동시간이 필요하다.
- 하루 진행 시 투입된 작업자와 노동시간 기준으로 가능한 작업량만큼 처리한다.
- `6박스`는 한 번에 끊어 처리하는 기준 단위이며, 하루 진행 시에는 남은 노동시간이 허용하는 만큼 여러 단위를 연속 처리할 수 있다.
- 실행 전에 작업 대상 요약 모달을 따로 띄우지 않고 바로 실행한다.
- 실행 버튼이 비활성화되어 있으면 비활성 사유를 버튼 근처에 표시한다.
- 꼭지제거 작업도 애니메이션을 재생한다.
- 애니메이션이 재생되는 동안 처리 대상 상자를 한 박스씩 순차 처리한다.
- `꼭지만 제거`는 각 박스가 처리 완료되는 순간 바로 `꼭지제거됨`으로 반영한다.
- 한 입력 박스가 `A급 / B급 / 가공품` 여러 잔량으로 쪼개지면, 해당 박스 처리 완료 시 그 결과를 모두 반영한다.
- 애니메이션 중 아직 처리되지 않은 상자는 작업 전 상태로 남는다.
- 작업 중에는 취소 버튼을 제공하지 않는다.
- 작업 중에는 저장을 막는다.
- 작업 중에는 전용 애니메이션 모달을 띄워 현재 회차 흐름만 진행한다.
- 전용 애니메이션 모달이 작업 흐름을 막아주면 별도의 강한 적재칸 잠금 로직은 필수로 두지 않아도 된다.
- 작업 완료 로그는 박스마다 남기지 않고 회차마다 하나만 남긴다.
- 예: `꼭지제거 완료: 후지 6박스 처리`

정확한 시간과 노동력 수치는 별도 밸런스 규칙이 정해지면 그 값을 따른다.

## 4-1. 보관 위치와 작업대

- 꼭지제거 작업 중 수확물이 일반저장으로 빠지면 안 된다.
- `꼭지 제거 + 부분선별` 결과물을 담을 선택된 `배출칸` 용량이 부족하면 작업을 시작하면 안 된다.
- `꼭지 제거 + 부분선별` 결과가 일부만 생성되고 나머지가 사라지거나 일반저장으로 빠지면 안 된다.
- 잔량 박스는 잔량 kg 그대로 처리하고, 20kg 만박스로 보정하면 안 된다.
- 0kg 결과 박스는 만들지 않는다.
- 1kg 미만 잔량은 내부 kg 값을 유지하고, 화면에는 `1kg 미만 잔량`으로 표시한다.
- 작업 중에는 전용 애니메이션 모달 기준으로 현재 회차 외 조작이 끼어들지 않게 한다.
- 작업 중에는 취소하지 않는다.
- 작업 완료 후에는 되돌리지 않는다.
- 작업이 완료되면 `꼭지제거 완료` 계열의 작업 로그를 남긴다.

## 4-2. 박스 순환 규칙

꼭지제거 작업의 상자는 사라지거나 새로 생기는 것이 아니라 `입력 박스 반환 -> 결과 박스 소모` 방식으로 순환한다.

- 입력으로 사용한 수확물 박스는 작업 후 빈 상자가 되어 현재 창고/토지의 일반 상자 재고로 돌아간다.
- 작업 결과를 담는 데 필요한 상자는 현재 창고/토지의 일반 상자 재고에서 다시 가져다 쓴다.
- `꼭지만 제거`처럼 입력 박스 수와 결과 박스 수가 같아도 이 순환 규칙을 따른다.
- `꼭지 제거 + 부분선별`처럼 결과 박스 수가 늘어날 수 있는 작업은 추가 상자가 필요할 수 있다.
- 결과 박스 수가 입력 박스 수보다 많으면 반환된 빈 상자만으로 부족할 수 있으므로, 부족분은 창고/토지 일반 상자 재고에서 더 소모한다.
- 필요한 상자가 부족하면 작업을 시작하면 안 된다.
- 작업 중 상자가 부족해서 일부 결과가 사라지거나 일반저장으로 빠지면 안 된다.

## 5. 표시 규칙

강조: 꼭지제거 전후 수확물 상세표시는 반드시 현재 작업 단계에 맞는 정보만 보여준다.

수확물 상세표시는 작업 단계별로 다음 필드 구조를 기준으로 한다.

- `과종`
- `품종`
- `품질명`
- `급`
- `다이`
- `꼭지여부`
- `kg`

값이 없는 필드는 다음 기본값을 사용한다.

- `급`이 없으면 `급 미정`
- `다이`가 없으면 `다이 미정`

단계별 표시는 다음을 따른다.

- 기본 수확 후: `과종 품종 품질명 급 미정 다이 미정 꼭지있음`
- 꼭지제거 작업 후: `과종 품종 품질명 급 미정 다이 미정 꼭지제거됨`
- 꼭지제거 + 부분선별 작업 후: `과종 품종 품질명 급 다이 미정 꼭지제거됨`
- 잔량 박스는 뒤에 `· nkg 잔량`만 추가한다.

예시는 다음과 같다.

- 기본 수확 후: `사과 후지 특상급 중하 급 미정 다이 미정 꼭지있음`
- 기본 수확 후 잔량 박스: `사과 후지 특상급 중하 급 미정 다이 미정 꼭지있음 · 7kg 잔량`
- 꼭지제거 작업 후: `사과 후지 특상급 중하 급 미정 다이 미정 꼭지제거됨`
- 꼭지제거 작업 후 잔량 박스: `사과 후지 특상급 중하 급 미정 다이 미정 꼭지제거됨 · 7kg 잔량`
- 꼭지제거 + 부분선별 작업 후: `사과 후지 특상급 중하 A급 다이 미정 꼭지제거됨`
- 꼭지제거 + 부분선별 작업 후 잔량 박스: `사과 후지 특상급 중하 A급 다이 미정 꼭지제거됨 · 7kg 잔량`

표시 의미는 다음과 같다.

- 기본 수확 후에는 품질명은 표시하지만, 급과 다이는 아직 정하지 않았으므로 `급 미정`, `다이 미정`으로 표시한다.
- 꼭지제거 작업 후에는 품질명과 급/다이 미정 상태를 유지하고, 꼭지 상태만 `꼭지제거됨`으로 바꾼다.
- 꼭지제거 + 부분선별 작업 후에는 `A급 / B급 / 가공품`까지 표시하지만, 다이는 아직 선별기 전이므로 `다이 미정`으로 표시한다.
- 선별기에서 최종 선별된 박스 상세는 선별기 규칙을 따라 `과종 품종 급 다이`만 표시한다.
- 하나의 박스에는 서로 다른 품종 수확물을 섞어 담지 않으며, 박스 표시는 항상 실제 단일 수확물 정보 기준으로 유지한다.

## 6. 상태 해석

작업 상태는 다음처럼 해석한다.

- `꼭지있음`: 아직 작업대 꼭지제거 작업 전 상태
- `꼭지제거됨`: 작업대 꼭지제거 작업을 마친 상태
- `급 미정`: 꼭지만 제거했거나 아직 부분선별 전 상태
- `다이 미정`: 선별기 투입 전 상태

즉, 작업대는 `꼭지 여부`와 `급`까지 확정할 수 있지만, `다이`는 선별기 단계에서만 확정한다.
