# 수확물/팔레트 이동 규칙

팔레트 적재, 개별 적재, 네온 결합, 빈 팔레트, 바닥 적재 관련 로직을 검토하거나 수정하기 전에 이 문서를 기준 규칙으로 확인한다.

## 1. 기본 개념

창고의 수확물 이동은 크게 두 방식이다.

- 팔레트째 이동: 팔레트 전체를 지게차 또는 팔레트잭으로 들어서 옮기는 방식
- 개별 적재: 팔레트, 바닥 적재칸, 운반기구 사이에서 박스를 1개씩 옮기는 방식

빈 팔레트도 팔레트 이동 대상이다.
개별 적재는 박스만 이동한다.
빈 팔레트 자체를 개별 적재 모드에서 박스처럼 옮기면 안 된다.

## 2. 팔레트째 이동

지게차 또는 팔레트잭은 팔레트를 직접 들어 원하는 적재칸으로 옮길 수 있다.
단, 차량 수확물 적재칸에 있는 팔레트를 싣거나 내리는 작업은 지게차만 가능하다.
팔레트잭은 바닥에 내려와 있는 팔레트나 창고/작업대/선별기 내부의 팔레트를 옮길 때만 사용한다.
차량 적재함 높이 때문에 팔레트잭으로 차량에 직접 싣거나 내릴 수 없다고 본다.

기본 흐름:

1. 운반기구 목록에서 지게차 또는 팔레트잭을 선택한다.
2. 창고의 팔레트 또는 빈 팔레트를 선택해 운반기구 적재칸에 싣는다.
3. 운반기구에 팔레트가 실린 상태에서 창고의 원하는 적재칸을 선택한다.
4. 선택한 적재칸으로 운반기구에 실린 팔레트를 내려놓는다.

팔레트째 이동 대상/실패 처리:

- 운반기구 적재칸에는 팔레트 1개만 실을 수 있다.
- 운반기구에 팔레트가 이미 실려 있으면 다른 수확물 팔레트나 빈 팔레트를 추가로 싣는 동작은 안 뜨거나 막혀야 한다.
- 팔레트를 내려놓을 대상은 완전히 빈 적재칸이어야 한다.
- 수확물 팔레트, 빈 팔레트, 바닥 적재가 있는 칸에는 다른 팔레트를 내려놓을 수 없다.
- 빈 팔레트도 완전히 빈 적재칸에만 내려놓을 수 있다.
- 수확물 팔레트도 완전히 빈 적재칸에만 내려놓을 수 있다.
- 바닥 적재 위에 팔레트를 얹으면 안 된다.
- 빈 팔레트 위에 수확물 팔레트나 다른 빈 팔레트를 덮어쓰면 안 된다.
- 팔레트째 이동이 실패하면 기존 적재물을 덮어쓰면 안 된다.
- 팔레트째 이동이 실패해도 들고 있던 팔레트가 사라지면 안 된다.
- 실패 시 이동 전 상태 또는 운반기구 적재 상태가 보존되어야 한다.

빈 팔레트:

- 지게차와 팔레트잭 모두 빈 팔레트를 이동할 수 있다.
- 운반기구에 실린 빈 팔레트는 빈 적재칸에 내려놓을 수 있어야 한다.
- 빈 팔레트를 취소하거나 빼면 현재 창고의 일반 빈 팔레트 재고/저장으로 돌아가면 된다.
- 출처를 반드시 보존할 필요는 없다.
- 단, 다른 적재물 위에 덮어쓰면 안 된다.

운반기구 선택 취소/회수:

- 운반기구에 팔레트가 실린 상태에서 `선택 취소`를 눌러도 팔레트가 원래 자리로 자동 복귀하지 않는다.
- `선택 취소`는 운반기구 선택과 현재 미리보기/결합 상태만 해제한다.
- 운반기구에 실제로 실려 있는 팔레트는 운반기구 적재칸에 그대로 남는다.
- 운반기구에 실린 빈 팔레트는 `꺼내기`로 현재 창고/토지의 빈 팔레트 재고에 1개 반환할 수 있다.
- 운반기구에 실린 수확물 팔레트는 자동 복귀하지 않고, 사용자가 다시 빈 적재칸에 내려놓아야 한다.
- 수확물 팔레트가 운반기구에 실린 상태에서도 박스 정보, 메모, 출처 성격의 데이터는 보존되어야 한다.

2단 적재:

- 지게차는 조건이 맞으면 2단 적재가 가능하다.
- 2단 적재는 이미 36박스가 모두 들어 있는 팔레트 위에만 가능하다.
- 팔레트잭은 2단 적재를 할 수 없다.
- 빈 팔레트나 36박스 미만 팔레트 위에는 2단 적재가 불가능하다.
- 창고 2단 적재는 아래 팔레트가 수확물 팔레트이고 36박스가 꽉 찬 경우에만 가능하다.
- 창고 2단 적재는 운반기구가 지게차일 때만 가능하다.
- 2단 적재된 슬롯에서는 위층 팔레트를 먼저 내려야 한다.
- 위층 팔레트가 남아 있으면 아래층 팔레트를 통째로 이동할 수 없다.
- 2단 적재된 슬롯은 아래층/위층을 개별 박스로 결합하지 않는다.
- 2단 적재된 슬롯 전체는 개별 적재 대상에서 제외된다.

## 3. 개별 적재

개별 적재는 박스를 1개씩 옮기는 기능이다.
지게차와 팔레트잭도 팔레트를 실은 뒤 개별 적재 모드로 전환하면 개별 적재가 가능하다.

지게차/팔레트잭 개별 적재 흐름:

1. 지게차 또는 팔레트잭으로 팔레트를 운반기구에 싣는다.
2. 운반기구 패널에서 `팔레트 적재` 모드를 `개별 적재` 모드로 바꾼다.
3. 개별 적재 대상이 될 적재칸을 선택한다.
4. 운반기구의 팔레트와 선택한 적재칸이 네온으로 결합 표시된다.
5. 네온 결합 상태에서 박스를 클릭하면 박스가 1개씩 이동한다.
6. 결합된 두 대상 사이에서는 양방향 이동이 가능하다.

개별 적재 가능한 대상:

- 빈 팔레트
- 36박스 미만 팔레트
- 36박스가 꽉 찬 팔레트
- 팔레트가 없는 빈 적재칸
- 바닥 적재칸
- 차량 수확물 적재칸
- 작업대 보관 공간
- 선별기 보관 공간
- 빈 팔레트끼리도 결합 가능하다.
- 단, 2단으로 쌓인 팔레트는 전체가 개별 적재 대상이 아니다.

2단 팔레트:

- 2단 팔레트는 아래층/위층을 나눠 개별 적재하지 않는다.
- 2단 팔레트 전체가 개별 적재 대상에서 제외된다.
- 2단 팔레트에는 `결합` 버튼이 뜨면 안 된다.

결합 규칙:

- 결합은 두 대상 사이에서 박스를 1개씩 주고받는 양방향 개별 박스 이동 상태를 뜻한다.
- 결합은 단순 선택 표시가 아니다. 결합된 두 대상은 서로 박스를 보낼 수도 있고 받을 수도 있어야 한다.
- 결합은 대상이 비었는지, 꽉 찼는지와 관계없이 무조건 가능하다.
- 꽉 찬 팔레트와 꽉 찬 팔레트끼리도 결합은 가능하다.
- 꽉 찬 바닥 적재칸과 꽉 찬 바닥 적재칸끼리도 결합은 가능하다.
- 결합된 두 대상 모두 이동할 빈 공간이 없으면 박스를 클릭해도 이동은 일어나지 않고, 적재할 곳이 다 찼다고 설명한다.
- 실제 이동 가능 여부는 박스를 클릭했을 때 판단한다.
- 대상이 꽉 차 있으면 결합은 유지되지만 그 방향 이동만 막힌다.
- 한쪽만 꽉 차 있으면 꽉 찬 쪽으로 넣는 이동만 막고, 반대 방향 이동은 계속 가능해야 한다.
- 빈 팔레트끼리 결합되어도 이동할 박스가 없으므로 아무 박스 이동은 일어나지 않는다.
- 이동할 박스가 없어서 이동할 수 없는 경우에는 경고를 띄울 필요 없다.
- 이동할 박스는 있지만 받을 수 있는 빈 공간이 없어서 이동할 수 없는 경우에는 적재할 곳이 다 찼다고 설명한다.
- 네온 결합 상태가 아닌 대상끼리는 박스를 주고받을 수 없다.
- 결합 대상이 완전히 비어도 자동으로 결합 해제되지 않는다.
- 결합 대상이 꽉 차도 자동으로 결합 해제되지 않는다.
- 결합 해제는 정해진 해제 조건에서만 일어난다.
- 결합된 대상에서 마지막 박스를 빼서 수확물 팔레트가 빈 팔레트로 바뀌어도 같은 적재칸이면 결합은 유지된다.
- 결합된 대상에서 마지막 박스를 빼서 바닥 적재가 빈 칸으로 바뀌어도 같은 적재칸이면 결합은 유지된다.
- 결합된 적재칸이 `빈 칸 -> 바닥 적재`, `빈 팔레트 -> 수확물 팔레트`, `수확물 팔레트 -> 빈 팔레트`, `바닥 적재 -> 빈 칸`으로 상태 전환되어도 같은 적재칸이면 결합 대상은 유지된다.
- 양쪽 모두 이동할 박스가 없으면 경고 없이 그대로 둔다.
- 한쪽에는 이동할 박스가 있지만 받는 쪽이 꽉 차서 이동이 막히는 경우에만 `적재할 곳이 다 찼습니다.`를 띄운다.

결합 대상 변경:

- A와 운반기구가 네온 결합된 상태에서 B의 `결합` 버튼을 누르면 기존 A 결합은 해제되고 B와 새로 결합된다.
- 동시에 여러 적재칸과 결합되면 안 된다.
- 다른 적재칸의 `결합` 버튼을 누르면 기존 결합은 해제되고 새 결합만 남아야 한다.

결합 해제 조건:

- `선택적재해제` 버튼을 누르면 결합이 해제된다.
- 모달을 닫으면 결합이 해제된다.
- 뒤로 가기를 누르면 결합이 해제된다.
- 운반기구 선택을 취소하면 결합이 해제된다.
- `결합해제` 버튼을 누르면 결합이 해제된다.
- 결합 대상이 비거나 꽉 찼다는 이유만으로 자동 해제되면 안 된다.
- 이동이 막혔다는 이유로 자동 해제되면 안 된다.
- 결합이 해제된 뒤에는 박스를 클릭해도 이전 대상과 박스를 주고받으면 안 된다.

## 4. 박스 이동 규칙

기본 이동:

- 한 번 클릭하면 반드시 박스 1개만 이동한다.
- 여러 박스가 한 번에 이동하면 안 된다.
- 한 번 클릭했는데 여러 박스가 연속 이동하거나 자동 이동되면 버그다.
- 사용자가 클릭한 바로 그 박스가 이동해야 한다.
- 위쪽 박스나 마지막 박스가 대신 이동하면 안 된다.
- 클릭한 박스가 중간이나 아래쪽에 있어도 그 박스가 빠져야 한다.
- 해당 박스가 빠진 뒤에는 그 박스가 있던 세로줄만 정리한다.
- 같은 세로줄에서 클릭한 박스보다 위에 있던 박스만 아래로 한 칸씩 내려온다.
- 옆 세로줄의 박스는 움직이면 안 된다.
- 팔레트 전체를 앞칸부터 다시 채우는 자동 재배치는 하지 않는다.
- 예: 3열 중간 박스를 빼면 3열 위쪽 박스만 아래로 내려오고, 1열·2열·4열·5열·6열은 그대로 둔다.
- 클릭한 세로줄의 맨 위쪽에는 새 빈칸이 생길 수 있다.
- 다른 박스가 대신 이동하면 안 된다.

세로줄 예시:

```text
이동 전

[위]
A
B
C  <- 사용자가 클릭한 박스
D
E
F
[아래]

이동 후

[위]
빈칸
A
B
D
E
F
[아래]
```

- C만 이동한다.
- C 위에 있던 A, B만 아래로 내려온다.
- C 아래에 있던 D, E, F는 그대로 둔다.
- 다른 세로줄의 박스는 움직이지 않는다.

박스 클릭 판정:

- 사용자가 마우스를 올렸을 때 호버링되어 살짝 떠오르는 박스가 선택 대상이다.
- 클릭하면 그 호버링된 박스가 이동해야 한다.
- 마우스 오버 툴팁에 표시된 박스와 실제 이동한 박스가 반드시 같아야 한다.
- 호버링된 박스와 실제 이동한 박스가 다르면 버그다.
- 겹쳐 보이는 영역이 있더라도 최종 기준은 현재 호버 상태인 박스다.
- 즉, hovered box = clicked box = moved box 여야 한다.

박스 정보:

- 한 팔레트나 바닥 적재칸에는 서로 다른 품종, 등급, 수확일, 잔량 박스가 섞일 수 있다.
- 섞여 있어도 각 박스는 개별 박스 단위로 식별되어야 한다.
- 마우스를 올렸을 때 해당 박스의 정보가 표시되어야 한다.
- 사용자가 클릭한 박스 정보와 실제 이동한 박스 정보가 일치해야 한다.

잔량 박스:

- 잔량 박스도 박스 1개로 취급한다.
- 클릭하면 1개 이동한다.
- 팔레트나 바닥 적재칸에 실릴 때도 박스 1칸을 차지한다.
- 일반 박스와 동일한 개별 적재 규칙을 따른다.
- 잔량 박스가 이동하면 kg 수량은 그 잔량만큼만 이동한다.
- 잔량 박스가 이동할 때 20kg 만박스로 보정되면 안 된다.

실패/중복 처리:

- 박스 클릭으로 이동이 실패해도 클릭한 박스 정보나 순서가 깨지면 안 된다.
- 결합 대상이 바뀌었을 때 이전에 클릭 대기 중이던 박스가 새 대상 쪽으로 자동 이동하면 안 된다.
- 경고 모달이 뜬 뒤 같은 클릭이 다시 처리되어 박스가 중복 이동하면 안 된다.

## 5. 수량 제한과 상태 전환

수량 제한:

- 팔레트 한 장에는 최대 36박스까지만 적재할 수 있다.
- 바닥 적재칸 한 칸에도 최대 36박스까지만 적재할 수 있다.
- 차량 수확물 적재칸의 바닥 적재는 한 칸당 최대 55박스까지 적재할 수 있다.
- 잔량 박스도 박스 1개로 보고 1칸을 차지한다.
- 36박스를 초과하는 이동은 막혀야 한다.
- 차량 바닥 적재는 55박스를 초과하는 이동이 막혀야 한다.
- 이동이 막혀도 네온 결합 상태는 유지되어야 한다.
- 차량 수확물 적재칸은 칸이 남아 있어도 차량 전체 적재중량을 넘으면 추가 적재가 막혀야 한다.
- 차량 적재중량 초과로 막혀도 네온 결합 상태는 유지하고 실제 박스 이동만 막는다.
- 차량 적재중량 초과 메시지는 `차량 적재한도를 초과합니다.`로 표시한다.
- 창고, 작업대, 선별기는 시설 전체 용량 kg이 부족하면 박스 칸이 남아 있어도 추가 적재가 막혀야 한다.
- 시설 전체 용량 부족으로 막혀도 네온 결합 상태는 유지하고 실제 박스 이동만 막는다.
- 시설 전체 용량 부족 메시지는 `저장공간 용량이 부족합니다.`로 표시한다.
- 박스 칸수 초과와 kg 용량 초과가 동시에 걸리면 칸수 초과를 우선해 `적재할 곳이 다 찼습니다.`를 표시한다.

꽉 찬 팔레트/바닥 적재칸:

- 36박스가 꽉 찬 팔레트도 결합은 가능하다.
- 36박스가 꽉 찬 바닥 적재칸도 결합은 가능하다.
- 꽉 찬 대상 안으로 추가 적재는 불가능하다.
- 꽉 찬 대상에서 박스를 빼는 방향은 가능해야 한다.
- 운반기구 쪽 팔레트나 적재칸에 여유가 있으면, 꽉 찬 대상에서 운반기구로 박스를 옮길 수 있어야 한다.

바닥 적재와 팔레트 적재 전환:

- 팔레트에서 빈 적재칸으로 박스를 옮기면 바닥 적재가 된다.
- 바닥 적재칸에서 빈 팔레트 위로 박스를 옮기면 팔레트 적재가 된다.
- 빈 차량 수확물 적재칸으로 박스를 옮기면 차량 바닥 적재가 된다.
- 빈 팔레트 위에 첫 박스가 올라가는 순간 해당 슬롯은 수확물 팔레트로 전환된다.
- 수확물 팔레트에서 마지막 박스를 빼면 팔레트 자체는 사라지지 않고 빈 팔레트로 남는다.
- 운반기구에 실린 팔레트도 마지막 박스를 빼면 빈 팔레트 상태로 남는다.
- 바닥 적재칸에서 마지막 박스를 빼면 빈 적재칸이 된다.

## 6. 개별 적재 전용 운반기구

맨손, 핸드카트, 플랫폼 카트는 팔레트째 이동이 불가능하고 개별 박스 적재만 가능하다.
이 운반기구들은 작은 팔레트처럼 취급한다.

적재 가능 수량:

- 맨손: 1박스
- 핸드카트: 4박스
- 플랫폼 카트: 8박스

개별 적재 전용 운반기구 규칙:

1. 운반기구를 선택한다.
2. 창고의 개별 적재 대상과 운반기구를 네온 결합한다.
3. 네온 결합 상태에서 박스를 클릭해 1개씩 이동한다.
4. 운반기구와 창고 적재칸 사이에서 양방향 이동이 가능하다.
5. 운반기구의 적재 가능 수량을 초과하면 이동이 막힌다.
6. 운반기구가 꽉 차도 결합은 유지된다.
7. 용량 초과 방향의 이동만 막힌다.
8. 반대로 운반기구에서 박스를 빼는 이동은 가능해야 한다.
9. 팔레트째 이동 버튼이나 팔레트 적재 동작은 나타나면 안 된다.
10. 운반기구가 꽉 찬 상태에서 더 넣으려 하면 `적재할 곳이 다 찼습니다.`를 띄운다.
11. 운반기구는 빈 상태에서도 결합 대상이 될 수 있다.
12. 운반기구가 첫 박스를 받으면 개별 박스 적재 상태가 된다.
13. 운반기구에서 마지막 박스를 빼면 빈 상태가 된다.
14. 운반기구에서 마지막 박스를 빼도 별도 팔레트나 저장공간이 생기면 안 된다.
15. 운반기구에 적재된 박스도 마우스 오버 시 박스 정보가 떠야 한다.
16. 운반기구에 적재된 박스를 클릭하면 클릭한 박스 1개만 이동해야 한다.
17. 맨손, 핸드카트, 플랫폼 카트는 팔레트가 아니므로 36칸/55칸 격자를 쓰지 않고, 각 장비 용량만큼의 작은 칸만 표시한다.

지게차/팔레트잭 개별 적재 추가 규칙:

- 지게차나 팔레트잭에 팔레트를 실은 뒤 `개별 적재` 모드로 바꾸면, 실린 팔레트의 박스를 1개씩 주고받는다.
- 지게차나 팔레트잭에 실린 팔레트가 빈 팔레트가 되어도 네온 결합은 유지된다.
- 지게차나 팔레트잭에 실린 빈 팔레트에 이동할 박스가 없으면 경고 없이 아무 이동도 일어나지 않는다.

## 7. 저장공간별 적용 규칙

창고, 작업대, 선별기, 차량 적재칸은 모두 수확물 저장공간으로 볼 수 있다.
다만 차량 적재칸은 바닥 적재 용량이 다르다.

공통 저장공간 규칙:

- 빈 팔레트, 수확물 팔레트, 바닥 적재 상태를 가질 수 있다.
- 팔레트 위에 적재되면 최대 36박스까지 적재할 수 있다.
- 팔레트가 없는 곳에 박스를 놓으면 바닥 적재가 된다.
- 수확물은 일반저장에 새로 보관하지 않는다.
- 수확물은 반드시 `팔레트 적재` 또는 `바닥 적재` 중 하나의 상태로만 저장한다.
- 과거 세이브 호환 때문에 일반저장 수확물 데이터가 발견되면 새 일반저장으로 유지하지 말고, 적재칸의 바닥 적재로 옮겨 해석하거나 마이그레이션한다.
- 네온 결합은 넓게 허용하고, 실제 이동 가능 여부는 박스 클릭 시점에 판단한다.
- 같은 칸 안에서 팔레트 적재와 바닥 적재가 동시에 섞이면 안 된다.
- 수확물 팔레트에서 마지막 박스를 빼면 빈 팔레트로 남는다.
- 바닥 적재에서 마지막 박스를 빼면 빈 저장공간이 된다.

창고 적재칸:

- 기본 저장공간이다.
- 팔레트 적재 최대 36박스, 바닥 적재 최대 36박스다.
- 지게차는 조건이 맞으면 36박스 팔레트 위에 2단 적재할 수 있다.
- 수확물은 일반저장으로 빠지면 안 되고, 반드시 팔레트 적재 또는 바닥 적재 상태로 유지되어야 한다.
- 완전히 빈 적재칸은 평소에는 박스 격자를 펼치지 않고 적재칸 상태만 표시한다.
- 완전히 빈 적재칸이 개별 적재 결합 대상일 때는 36칸 빈 격자 UI 틀을 쓴다.
- 빈 팔레트는 박스 격자를 펼치지 않고 빈 팔레트 상태만 표시한다.
- 바닥 적재는 36칸 격자 UI 틀을 쓴다.
- 바닥 적재에서 마지막 박스를 빼면 빈 칸으로 돌아간다.
- 수확물 팔레트는 36칸 격자 UI 틀을 쓴다.
- 수확물 팔레트에서 마지막 박스를 빼면 빈 팔레트로 남는다.
- 빈 적재칸에 `팔레트 적재`를 누르면 빈 팔레트 재고를 1개 차감하고 빈 팔레트 상태로 만든다.
- 빈 팔레트를 `꺼내기` 하면 빈 팔레트 재고로 1개 돌아간다.
- 바닥 적재는 팔레트가 아니므로 지게차나 팔레트잭으로 통째 이동할 수 없고, 개별 박스 이동만 가능하다.
- 창고 2단 적재는 지게차만 가능하고 팔레트잭은 할 수 없다.
- 2단 적재된 창고 슬롯은 전체가 개별 적재 대상에서 제외되며 `결합` 버튼이 뜨면 안 된다.

작업대 보관 공간:

- 임시 작업칸이 아니라 저장공간으로 취급한다.
- 창고 적재칸과 같은 방식으로 빈 팔레트, 수확물 팔레트, 바닥 적재를 지원한다.
- 팔레트 적재 최대 36박스, 바닥 적재 최대 36박스다.
- 현재 규칙에서는 2단 적재 대상이 아니다.
- 수확물 팔레트에서 마지막 박스를 빼면 빈 팔레트로 남는다.
- 바닥 적재에서 마지막 박스를 빼면 빈 칸으로 돌아간다.
- 빈 팔레트도 개별 적재 모드에서 `결합` 대상이다.
- 빈 팔레트에 첫 박스를 넣으면 수확물 팔레트로 전환된다.
- 완전히 빈 칸에 개별 적재로 첫 박스를 넣으면 바닥 적재로 전환된다.
- 수확물이 일반저장으로 빠지면 안 되고, 반드시 팔레트 적재 또는 바닥 적재 상태로 유지되어야 한다.
- 작업대 보관 공간의 팔레트는 지게차와 팔레트잭 모두 통째 이동할 수 있다.
- 작업대 보관 공간의 바닥 적재는 팔레트가 아니므로 통째 이동할 수 없고, 개별 박스 이동만 가능하다.
- 작업대 보관 공간이 꽉 차 있어도 `결합` 버튼은 떠야 하고, 넣는 방향만 막힌다.
- 꽉 찬 작업대 보관 공간으로 박스를 넣으려 하면 `적재할 곳이 다 찼습니다.`를 띄우고 네온 결합 상태는 유지한다.

선별기 보관 공간:

- 창고 적재칸과 같은 방식으로 빈 팔레트, 수확물 팔레트, 바닥 적재를 지원한다.
- 팔레트 적재 최대 36박스, 바닥 적재 최대 36박스다.
- 선별 작업은 이 저장공간의 수확물을 별도 작업 로직이 사용하는 것으로 본다.
- 현재 규칙에서는 2단 적재 대상이 아니다.
- 수확물 팔레트에서 마지막 박스를 빼면 빈 팔레트로 남는다.
- 바닥 적재에서 마지막 박스를 빼면 빈 칸으로 돌아간다.

- 빈 팔레트에 첫 박스를 넣으면 수확물 팔레트로 전환된다.
- 완전히 빈 칸에 개별 적재로 첫 박스를 넣으면 바닥 적재로 전환된다.
- 수확물이 일반저장으로 빠지면 안 되고, 반드시 팔레트 적재 또는 바닥 적재 상태로 유지되어야 한다.

차량 수확물 적재칸:

- 차량 일반 적재함이 아니라 수확물을 싣는 전용 적재칸이다.
- 차량 수확물 적재칸의 기본 적재 규칙은 창고 적재칸과 동일하게 본다.
- 차량 수확물 적재칸이 창고 적재칸과 달라지는 예외는 다음 3개뿐이다.
- 예외 1: 차량 수확물 적재칸의 팔레트는 팔레트잭으로 싣거나 내릴 수 없고 지게차만 가능하다.
- 예외 2: 차량 수확물 적재칸의 바닥 적재는 한 칸당 최대 55박스다.
- 예외 3: 차량 수확물 적재칸에는 팔레트 2단 적재를 할 수 없다.
- 차량 수확물 적재칸의 버튼 노출 방식은 기본적으로 창고 수확물 적재칸과 같은 기준을 따른다.
- 완전히 빈 칸, 빈 팔레트, 수확물 팔레트, 바닥 적재에서 어떤 버튼이 뜨는지도 기본적으로 창고와 같은 흐름으로 본다.
- 단, 차량에서만 필요한 예외 규칙이 있으면 그 예외를 우선 적용한다.
- 차량 수확물 적재칸 UI는 적재 방식의 실제 용량에 맞는 격자 형태로 표시한다.
- 완전히 빈 적재칸은 평소에는 박스 격자를 펼치지 않고 적재칸 상태만 표시한다.
- 완전히 빈 적재칸이 개별 적재 결합 대상일 때는 차량 바닥 적재 후보로 보고 55칸 빈 격자 UI 틀을 쓴다.
- 수확물 팔레트는 36칸 격자 UI 틀을 쓴다.
- 빈 팔레트는 박스 격자를 펼치지 않고 팔레트 적재 상태만 표시한다.
- 차량 바닥 적재 상태는 55칸 격자 UI 틀을 쓴다.
- 팔레트가 있으면 팔레트 적재로 보고 최대 36박스까지 적재한다.
- 팔레트가 없으면 바닥 적재로 보고 한 칸당 최대 55박스까지 적재한다.
- 같은 차량 적재칸 안에서 팔레트 적재와 바닥 적재가 동시에 섞이면 안 된다.
- 차량 수확물 적재칸의 `팔레트 적재` 버튼은 완전히 빈 적재칸에만 뜬다.
- 차량 수확물 적재칸에 이미 빈 팔레트, 수확물 팔레트, 바닥 적재가 있으면 `팔레트 적재` 버튼이 뜨면 안 된다.
- 차량 바닥 적재 상태인 칸에는 빈 팔레트를 추가로 깔 수 없다.
- 차량 바닥 적재 상태인 칸은 박스를 모두 비워 완전히 빈 적재칸으로 돌아간 뒤에만 팔레트를 적재할 수 있다.
- 차량 수확물 적재칸에 빈 팔레트를 깔 때는 현재 창고/토지의 빈 팔레트 재고를 1개 차감한다.
- 차량 수확물 적재칸의 빈 팔레트는 평소에는 `꺼내기` 버튼만 보이고, 개별 적재 모드에서는 `결합` 버튼이 떠야 한다.
- 차량 수확물 적재칸의 수확물 팔레트는 평소에는 상세 보기와 박스 정보 확인이 가능해야 하고, 개별 적재 모드에서는 `결합` 버튼이 떠야 한다.
- 차량 수확물 적재칸의 바닥 적재도 평소에는 상세 보기와 박스 정보 확인이 가능해야 하고, 개별 적재 모드에서는 `결합` 버튼이 떠야 한다.
- 차량 수확물 적재칸의 수확물 팔레트와 빈 팔레트는 지게차로 통째로 내릴 수 있어야 한다.
- 차량 수확물 적재칸에 있는 수확물 팔레트와 빈 팔레트는 팔레트잭으로 통째로 내릴 수 없다.
- 차량 바닥 적재는 팔레트가 아니므로 지게차나 팔레트잭으로 통째 이동할 수 없고, 개별 박스 이동만 가능하다.
- 차량 수확물 적재칸에 이미 수확물 팔레트가 있으면 다른 팔레트를 그 위에 2단 적재하는 버튼이 절대 뜨면 안 된다.
- 차량 수확물 적재칸에 이미 빈 팔레트가 있으면 다른 빈 팔레트나 수확물 팔레트를 겹쳐 놓을 수 없다.
- 차량 수확물 적재칸에 실린 팔레트에서 마지막 박스를 빼면 빈 팔레트로 남는다.
- 차량 수확물 적재칸의 바닥 적재에서 마지막 박스를 빼면 빈 칸이 된다.
- 차량 수확물 적재칸의 빈 팔레트를 `꺼내기` 하면 현재 창고/토지의 빈 팔레트 재고로 1개 돌아간다.
- 차량 수확물 팔레트에서 마지막 박스를 빼서 빈 팔레트가 된 뒤에도 `꺼내기`로 회수할 수 있어야 한다.
- 차량 바닥 적재는 팔레트가 없는 상태이므로 마지막 박스를 빼도 빈 팔레트 재고가 늘어나면 안 된다.
- 차량 수확물 적재칸은 개별 적재 결합 대상이다.
- 완전히 빈 차량 수확물 적재칸은 첫 박스를 받으면 차량 바닥 적재 상태가 된다.
- 빈 팔레트가 있는 차량 적재칸은 결합 가능하고 개별 적재가 가능하다.
- 빈 팔레트가 있는 차량 적재칸은 박스가 없어도 개별 적재 모드에서 `결합` 버튼이 떠야 한다.
- 완전히 빈 차량 수확물 적재칸도 개별 적재 모드에서는 차량 바닥 적재 후보이므로 55칸 빈 격자와 `결합` 버튼이 떠야 한다.
- 빈 팔레트가 있는 차량 적재칸은 첫 박스를 받으면 수확물 팔레트로 전환된다.
- 수확물이 들어 있는 팔레트가 있는 차량 적재칸도 결합 가능하고 개별 적재가 가능하다.
- 이미 수확물이 있는 차량 적재칸도 남은 칸이 있으면 개별 적재로 추가 결합할 수 있다.
- 차량 수확물 적재칸이 꽉 차 있어도 결합 자체는 가능하고, 실제 추가 이동만 막힌다.
- 차량 수확물 팔레트가 36박스로 꽉 차 있어도 `결합` 버튼은 계속 떠야 한다.
- 차량 바닥 적재가 55박스로 꽉 차 있어도 `결합` 버튼은 계속 떠야 한다.
- 차량 바닥 적재가 55박스로 꽉 차 있어도 박스를 빼는 방향은 가능해야 한다.
- 꽉 찬 차량 적재칸으로 박스를 넣으려 하면 `적재할 곳이 다 찼습니다.`를 띄우고 네온 결합 상태는 유지한다.
- 차량 빈 팔레트끼리 결합된 경우에는 이동할 박스가 없으므로 경고 없이 아무 이동도 일어나지 않는다.
- 현재 규칙에서는 차량 수확물 적재칸 위 2단 적재는 불가능하다.

차량 일반 적재함:

- 현재 수확물 이동 규칙의 대상에서 제외한다.
- 수확물을 차량 일반 적재함에 넣는 흐름은 만들지 않는다.
- 차량의 수확물 관련 UI 탭 이름은 `팔레트 자리`보다 `수확물`이 더 정확하다.
- 이유: 같은 칸이 팔레트 적재뿐 아니라 바닥 적재도 할 수 있기 때문이다.

## 8. 경고 모달 이후 상태

- 36박스 초과 경고가 떠도 네온 결합은 유지한다.
- 운반기구 용량 초과 경고가 떠도 네온 결합은 유지한다.
- 이동 불가 경고가 떠도 네온 결합은 유지한다.
- 단, 방금 클릭한 박스 선택/임시 이동 상태만 초기화한다.
- 경고 이후 다른 결합 버튼을 눌렀다고 자동으로 박스가 이동하면 안 된다.

## 9. 대상 목록/운반장비 표시

수확물 이동 목적지:

- 수확물 이동 목적지 목록에는 수확물 적재칸이 있는 창고, 작업대, 선별기, 차량만 표시한다.
- 일반저장만 가능한 공간이나 수확물 적재칸이 없는 시설은 목적지 목록에서 제외한다.
- 차량 목적지는 차량 일반 적재함이 아니라 수확물 적재칸이 있는 차량만 표시한다.
- 차량에 수확물 적재칸이 있어도 모든 칸이 장비 적재로 막혀 있으면 목적지 목록에서 제외한다.

운반장비 목록:

- 운반모달의 운반장비 목록에는 실제로 수확물 이동이 가능한 장비만 표시한다.
- 맨손, 핸드카트, 플랫폼 카트는 개별 이동 장비로 표시한다.
- 맨손, 핸드카트, 플랫폼 카트는 팔레트째 이동 장비로 표시하면 안 된다.
- 지게차와 팔레트잭은 팔레트째 이동 장비로 표시한다.
- 지게차와 팔레트잭은 팔레트를 실은 뒤 개별 적재 모드도 선택할 수 있다.
- 팔레트잭이 운반장비 목록에 있어도 차량에 팔레트를 싣거나 내리는 대상에서는 불가 처리한다.

안내 문구:

- 팔레트째 이동 대상 선택 시 운반기구가 없으면 `운반기구를 먼저 선택해 주세요.`를 띄운다.
- 개별 적재 모드에서 결합 대상 없이 박스를 클릭하면 `결합 대상을 먼저 선택해 주세요.`를 띄운다.

## 10. 버그 판정 기준

다음 상황은 모두 버그다.

팔레트째 이동 관련:

- 지게차/팔레트잭에 팔레트를 실었는데 선택 취소 후 다시 선택하면 팔레트가 사라진다.
- 팔레트 적재 모드와 개별 적재 모드를 전환했을 때 실려 있던 팔레트나 빈 팔레트가 사라진다.
- 빈 팔레트를 들고 있는데 빈 적재칸에 `놓기` 버튼이 안 뜬다.
- 빈 팔레트를 내려놓거나 빼는 과정에서 다른 적재물을 덮어쓴다.
- 지게차가 아닌 운반기구에서 2단 적재가 가능하다.
- 36박스가 아닌 팔레트 위에 2단 적재가 가능하다.

개별 적재/결합 관련:

- 개별 적재 대상인데 `결합` 버튼이 안 뜬다.
- 차량 수확물 적재칸이 개별 적재 대상인데 `결합` 버튼이 안 뜬다.
- 차량 수확물 적재칸 UI가 창고 수확물 적재칸과 다른 격자 구조로 표시된다.
- 2단 팔레트에 `결합` 버튼이 뜬다.
- 네온 결합이 안 된 상태에서 박스가 이동한다.
- 네온 결합 상태인데 박스가 양방향으로 이동하지 않는다.
- 결합 대상이 비었다고 자동으로 결합 해제된다.
- 결합 대상이 꽉 찼다고 자동으로 결합 해제된다.
- 이동이 막혔다는 이유로 네온 결합이 자동 해제된다.
- `선택적재해제`를 누르지 않았고 닫기/뒤로/운반기구 선택취소도 하지 않았는데 결합이 풀린다.
- A와 결합된 상태에서 B를 결합했는데 A와 B가 동시에 결합 상태로 남는다.

박스 이동 관련:

- 박스 1개 클릭에 2개 이상 이동한다.
- 호버링된 박스가 아니라 다른 박스가 이동한다.
- 클릭한 박스가 중간/아래쪽에 있다는 이유로 이동하지 않는다.
- 박스가 빠진 뒤 중간에 빈칸이 남는다.
- 여러 종류의 박스가 섞여 있는데 특정 박스를 선택할 수 없다.
- 마우스 오버로 표시된 박스 정보와 실제 이동한 박스 정보가 다르다.
- 잔량 박스가 박스 1개로 취급되지 않는다.

수량/상태 전환 관련:

- 팔레트에 36박스를 초과해서 적재된다.
- 바닥 적재칸에 36박스를 초과해서 적재된다.
- 차량 수확물 적재칸의 팔레트에 36박스를 초과해서 적재된다.
- 차량 수확물 적재칸의 바닥 적재에 55박스를 초과해서 적재된다.
- 차량 수확물 적재칸 한 칸 안에서 팔레트 적재와 바닥 적재가 동시에 섞인다.
- 작업대 보관 공간이나 선별기 보관 공간이 저장공간처럼 동작하지 않는다.
- 차량 일반 적재함에 수확물 적재 흐름이 나타난다.
- 36박스 꽉 찬 팔레트에서 박스를 빼지 못한다.
- 36박스 꽉 찬 바닥 적재칸에서 박스를 빼지 못한다.
- 빈 팔레트 위에 첫 박스를 올렸는데 수확물 팔레트로 전환되지 않는다.
- 수확물 팔레트에서 마지막 박스를 뺐는데 빈 팔레트로 남지 않는다.
- 운반기구에 실린 팔레트에서 마지막 박스를 뺐는데 빈 팔레트로 남지 않는다.
- 바닥 적재칸에서 마지막 박스를 뺐는데 빈 적재칸으로 바뀌지 않는다.
- 36박스 초과 경고 후 다른 결합 버튼을 누르면 자동으로 1박스가 이동한다.

개별 적재 전용 운반기구 관련:

- 맨손에 2박스 이상 적재된다.
- 핸드카트에 5박스 이상 적재된다.
- 플랫폼 카트에 9박스 이상 적재된다.
- 맨손/핸드카트/플랫폼 카트에서 팔레트째 적재 동작이 나타난다.
- 운반기구가 꽉 찼다는 이유로 결합이 자동 해제된다.
- 운반기구가 꽉 찼을 때 운반기구에서 박스를 빼는 이동까지 막힌다.

## 핵심 원칙

```text
1. 결합은 넓게 허용한다.
2. 실제 이동 가능 여부는 박스 클릭 시점에 판단한다.
3. 이동이 불가능해도 결합 상태는 유지한다.
4. hovered box = clicked box = moved box 여야 한다.
```
