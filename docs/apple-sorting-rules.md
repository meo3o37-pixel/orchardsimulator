# 사과 선별 규칙

사과 선별기 로직을 검토하거나 수정하기 전에 이 문서를 기준 규칙으로 확인한다.

## 1. 기본 개념

사과 선별은 `품질 선별`과 `크기 선별`을 분리해서 처리한다.

- 1차 선별: 품질에 따라 `A급`, `B급`, `가공품`으로 나눈다.
- 2차 선별: `A급`, `B급`, `가공품`을 모두 다시 `1다이 ~ 10다이` 기준으로 나눈다.
- `가공품`도 별도 가공용 등급으로 유지하되, 크기 분류는 `1다이 ~ 10다이`까지 모두 적용한다.

즉, 품질은 상품성 판단 기준이고 다이는 과실 크기 판단 기준이다.
두 기준은 같은 축으로 합치지 않는다.

## 2. 입력 규칙

선별 계산 입력값은 다음 두 가지다.

- 총 물량 `totalKg`
- 품질 `quality` 0~100

입력 보정 규칙:

- 품질이 0 미만이면 0으로 보정한다.
- 품질이 100 초과면 100으로 보정한다.
- 총 물량이 0 이하이면 모든 선별 결과는 0으로 처리한다.

## 3. 1차 선별 규칙

품질이 낮을수록 `가공품` 비율이 높아진다.
품질이 높을수록 `A급` 비율이 높아진다.
`B급`은 중간 완충 구간 역할을 한다.

핵심 원칙:

- 최저 품질에서도 `A급`과 `B급`은 완전 0%로 만들지 않는다.
- 최고 품질에서도 `가공품`은 완전 0%로 만들지 않는다.
- 같은 품질과 같은 물량이면 같은 선별 비율이 나온다.

## 4. 품질별 기본 비율 기준

품질별 `A급 / B급 / 가공품` 기준점은 다음과 같다.

- 품질 `0`: `A급 1%`, `B급 3%`, `가공품 96%`
- 품질 `10`: `A급 1.5%`, `B급 4.5%`, `가공품 94%`
- 품질 `20`: `A급 3%`, `B급 8%`, `가공품 89%`
- 품질 `30`: `A급 6%`, `B급 14%`, `가공품 80%`
- 품질 `40`: `A급 12%`, `B급 20%`, `가공품 68%`
- 품질 `50`: `A급 20%`, `B급 26%`, `가공품 54%`
- 품질 `60`: `A급 32%`, `B급 28%`, `가공품 40%`
- 품질 `70`: `A급 46%`, `B급 27%`, `가공품 27%`
- 품질 `80`: `A급 60%`, `B급 23%`, `가공품 17%`
- 품질 `90`: `A급 73%`, `B급 18%`, `가공품 9%`
- 품질 `100`: `A급 84%`, `B급 13%`, `가공품 3%`

## 5. 비율 계산 규칙

기준점 사이 품질값은 선형 보간으로 계산한다.

예:

- 품질 `35`는 품질 `30`과 `40` 사이를 비례로 섞는다.
- 품질 `77`은 품질 `70`과 `80` 사이를 비례로 섞는다.

계산된 `A급`, `B급`, `가공품` 값은 합계가 100%가 되도록 정규화한다.

## 6. 2차 선별 규칙

`A급`, `B급`, `가공품`은 각각 전용 다이 분포표를 사용한다.

- `A급`은 A급 전용 다이 분포표를 사용한다.
- `B급`은 B급 전용 다이 분포표를 사용한다.
- `가공품`은 가공품 전용 다이 분포표를 사용한다.

품질이 바뀌면 다이 분포도 함께 변한다.

- 저품질일수록 작은 과 비중이 높아진다.
- 고품질일수록 큰 과 비중이 높아진다.
- 저품질이어도 큰 과가 완전히 0이 되지 않게 한다.
- 고품질이어도 작은 과가 완전히 0이 되지 않게 한다.

## 7. A급 크기 분포 규칙

A급은 전반적으로 상품 출하용이므로, 같은 품질에서도 B급보다 큰 과 비중이 높다.

기본 경향:

- 저품질 A급은 `7~9다이` 중심으로 배출된다.
- 중간 품질 A급은 `4~7다이` 중심으로 배출된다.
- 고품질 A급은 `1~5다이` 비중이 크게 증가한다.
- 저품질이어도 `3~4다이`는 극소량 남긴다.
- 고품질이어도 `8~9다이`는 극소량 남긴다.

## 8. B급 크기 분포 규칙

B급은 전반적으로 A급보다 작은 과와 하위 등급 비중이 높다.

기본 경향:

- 저품질 B급은 `7~10다이` 중심으로 배출된다.
- 중간 품질 B급은 `5~8다이` 중심으로 배출된다.
- 고품질 B급은 `3~6다이` 비중이 늘어나지만 A급만큼 큰 과 쪽으로 가지는 않는다.
- `10다이`는 B급과 가공품 경계 성격을 가지며 저품질에서 비중이 특히 커진다.
- 저품질이어도 `3~4다이`는 극소량 남긴다.

## 9. 다이 분류 기준

- `1다이`: 초특대과, `8~10과`, `560g`
- `2다이`: 특특대과, `10~12과`, `460g`
- `3다이`: 특대과, `12~14과`, `390g`
- `4다이`: 대과, `14~16과`, `335g`
- `5다이`: 중과, `16~18과`, `295g`
- `6다이`: 중소과, `18~20과`, `265g`
- `7다이`: 소과, `20~23과`, `235g`
- `8다이`: 소소과, `23~26과`, `205g`
- `9다이`: 극소과, `26~30과`, `180g`
- `10다이`: 가공과, `30과 이상`, `160g`

## 10. 물량 배분 규칙

등급별 물량과 다이별 물량은 kg 기준으로 계산한다.

- 등급별 물량 = `총 물량 × 등급 비율`
- 다이별 물량 = `등급 물량 × 해당 등급의 다이 비율`

최종 출력은 다음 형태로 정리한다.

- `A급 다이별 kg`
- `B급 다이별 kg`
- `가공품 다이별 kg`

## 11. 가공품 처리 규칙

가공품은 별도 가공용 등급으로 유지하되, 크기 선별도 함께 적용한다.

- 내부 계산상 `가공품`은 별도 등급으로 유지한다.
- 가공품도 `1다이 ~ 10다이`로 다시 나눈다.
- 가공품은 출하용 A급, B급과 동일한 상품 등급으로 취급하지 않는다.

## 12. 현실성 규칙

현실성을 위해 극단값을 완전히 잘라내지 않는다.

- 품질이 낮다고 해서 큰 과가 완전히 사라지지는 않는다.
- 품질이 높다고 해서 작은 과가 완전히 사라지지는 않는다.
- 최저 품질에서도 극소량의 `A급`, `B급`은 남길 수 있다.
- 최고 품질에서도 소량의 `가공품`은 발생할 수 있다.

즉, 선별 결과는 중심 경향은 분명하지만 꼬리는 남기는 방향으로 유지한다.

## 13. 표시 규칙

강조: 수확물 상세표시는 반드시 현재 작업 단계에 맞는 정보만 보여준다.

수확물 상세표시는 작업 단계별로 다음 형식을 기본으로 한다.

- 기본 수확 후: `과종 품종 품질명 급 미정 다이 미정 꼭지있음`
- 꼭지제거 작업 후: `과종 품종 품질명 급 미정 다이 미정 꼭지제거됨`
- 꼭지제거 + 부분선별 작업 후: `과종 품종 품질명 급 다이 미정 꼭지제거됨`
- 선별기에서 선별 후: `과종 품종 급 다이`

예시는 다음과 같다.

- 기본 수확 후: `사과 후지 특상급 중하 급 미정 다이 미정 꼭지있음`
- 기본 수확 후 잔량 박스: `사과 후지 특상급 중하 급 미정 다이 미정 꼭지있음 · 7kg 잔량`
- 꼭지제거 작업 후: `사과 후지 특상급 중하 급 미정 다이 미정 꼭지제거됨`
- 꼭지제거 작업 후 잔량 박스: `사과 후지 특상급 중하 급 미정 다이 미정 꼭지제거됨 · 7kg 잔량`
- 꼭지제거 + 부분선별 작업 후: `사과 후지 특상급 중하 A급 다이 미정 꼭지제거됨`
- 꼭지제거 + 부분선별 작업 후 잔량 박스: `사과 후지 특상급 중하 A급 다이 미정 꼭지제거됨 · 7kg 잔량`
- 선별기에서 선별 후: `사과 후지 A급 3다이`
- 선별 후 잔량 박스: `사과 후지 A급 3다이 · 7kg 잔량`

표시 의미는 다음과 같다.

- 기본 수확 후에는 품질명은 표시하지만, 급과 다이는 아직 정하지 않았으므로 `급 미정`, `다이 미정`으로 표시한다.
- 꼭지제거 작업 후에는 품질명과 급/다이 미정 상태를 유지하고, 꼭지 상태만 `꼭지제거됨`으로 바꾼다.
- 꼭지제거 + 부분선별 작업 후에는 `A급 / B급 / 가공품`까지 표시하지만, 다이는 아직 선별기 전이므로 `다이 미정`으로 표시한다.
- 선별기에서 선별 후에는 최종 판매/보관 기준인 `과종 품종 급 다이`만 표시한다.

선별기에서 최종 선별된 박스 상세에는 `품질`, `꼭지상태`, `박스 수량`을 표시하지 않는다.

## 14. 운영 규칙

- 선별기 실행 시 이 규칙은 입력된 품질과 물량에 대해 항상 동일하게 적용한다.
- 같은 품질과 같은 물량이면 같은 결과 비율이 나와야 한다.
- 랜덤성을 도입하더라도 기본 비율표를 중심으로 작은 변동만 허용하는 것을 원칙으로 한다.
- 선별 로직을 수정할 때는 `품질 비율표`, `A급 다이 분포`, `B급 다이 분포`, `가공품 처리 방식`을 함께 확인한다.

## 15. 선별기 투입 규칙

실제 선별기 운용에서는 계산 규칙과 별도로 다음 투입 조건을 따른다.

- 선별기 투입 단위는 `상자`다.
- 선별기 실행 전 현재 창고의 수확물 적재칸 중 일부를 `투입칸`과 `배출칸`으로 지정한다.
- 실제 선별 대상은 사용자가 지정한 `투입칸`에 들어 있는 상자만 본다.
- 선별기에 넣을 수 있는 것은 `같은 품종`의 사과만 허용한다.
- 선별기에 넣을 수 있는 것은 `꼭지 제거가 완료된 상자`만 허용한다.
- `꼭지만 제거된 급 미정 박스`와 `부분선별까지 끝난 다이 미정 박스`는 같은 회차에 섞어 선별하지 않는다.
- `꼭지만 제거된 급 미정 박스`를 넣으면 선별기는 `1차 품질 선별 + 2차 다이 선별`을 모두 수행한다.
- `부분선별까지 끝난 A급 / B급 / 가공품 다이 미정 박스`를 넣으면 선별기는 `2차 다이 선별`만 수행한다.
- `부분선별까지 끝난 다이 미정 박스`는 같은 품종이라도 `같은 급`끼리만 한 회차에 같이 선별할 수 있다.
- 즉 `A급 다이 미정`은 `A급 다이 미정`끼리만, `B급 다이 미정`은 `B급 다이 미정`끼리만, `가공품 다이 미정`은 `가공품 다이 미정`끼리만 선별한다.
- 서로 다른 품종을 한 번에 같이 선별하면 안 된다.
- 꼭지 제거가 되지 않은 상자는 선별기에 투입하면 안 된다.

## 16. 선별기 결과물 규칙

- 선별 결과물 저장 단위도 `상자`다.
- 선별 결과는 사용자가 지정한 `배출칸` 안에서만 배치한다.
- 결과 저장 위치를 작업대나 일반 창고로 자동 이동시키지 않는다.
- `가공품`으로 빠진 물량도 상세 표시는 `과종 품종 가공품 n다이` 형식을 따른다.
- 한 박스 상세표시에는 상자 수량을 붙이지 않는다.
- 한 적재칸에는 `같은 과종 / 같은 품종 / 같은 급 / 같은 다이 / 같은 박스종류`만 적재한다.

박스 순환 규칙:

- 선별기의 상자는 사라지거나 새로 생기는 것이 아니라 `입력 박스 반환 -> 결과 박스 소모` 방식으로 순환한다.
- 입력으로 사용한 수확물 박스는 선별 후 빈 상자가 되어 현재 창고/토지의 일반 상자 재고로 돌아간다.
- 선별 결과를 담는 데 필요한 상자는 현재 창고/토지의 일반 상자 재고에서 다시 가져다 쓴다.
- 선별 결과가 여러 등급, 다이, 잔량 박스로 나뉘면 결과 박스 수가 입력 박스 수보다 늘어날 수 있다.
- 결과 박스 수가 입력 박스 수보다 많으면 반환된 빈 상자만으로 부족할 수 있으므로, 부족분은 창고/토지 일반 상자 재고에서 더 소모한다.
- 필요한 상자가 부족하면 선별 작업을 시작하면 안 된다.
- 작업 중 상자가 부족해서 일부 결과가 사라지거나 일반저장으로 빠지면 안 된다.
- 선별 입력 박스의 빈 상자는 현재 창고/토지의 일반 상자 재고로 돌아간다.
- 선별 결과 박스에 필요한 새 상자는 해당 창고/토지의 상자 재고에서 가져다 쓴다.
- 결과가 여러 등급, 다이, 잔량 박스로 쪼개지면 필요한 만큼 상자를 소모한다.
- 선별 후 잔량 상자는 과종, 품종, 급, 다이, 박스종류가 같은 잔량 상자끼리 가능한 만큼 합친다.
- 같은 조건의 잔량 상자끼리는 20kg 만박스를 만들 수 있으면 만들고, 남는 kg만 잔량 박스로 둔다.
- 예: 같은 조건의 7kg 잔량 상자와 13kg 잔량 상자는 20kg 1박스로 합친다.
- 예: 같은 조건의 7kg 잔량 상자와 8kg 잔량 상자는 15kg 잔량 1박스로 합친다.
- 같은 조건의 잔량 박스는 선택된 `배출칸` 안에서만 먼저 합친다.
- 새 결과 박스도 선택된 `배출칸` 안에서만 배치한다.
- 결과 박스 배치 순서는 `A급 -> B급 -> 가공품`을 기본으로 한다.
- 합치는 과정에서 박스 수가 줄면 줄어든 빈 상자는 현재 창고/토지의 일반 상자 재고로 돌아간다.
- 작업 시작 전 필요한 상자 수는 합친 뒤 최종 결과 박스 수 기준으로 계산한다.
- 합친 뒤 최종 결과 박스 수가 입력 박스 수보다 적으면 남는 빈 상자는 현재 창고/토지의 일반 상자 재고로 돌아간다.
- 선별 결과 kg 합계는 입력 kg 합계와 같아야 한다.
- 결과 박스 수가 늘어날 수 있다.
- 필요한 상자가 부족하면 선별 작업을 시작하면 안 된다.
- 작업 중 상자가 부족해서 일부만 만들고 나머지가 사라지면 안 된다.

예:

- `사과 후지 가공품 3다이`
- `사과 후지 가공품 10다이`

## 17. 선별기 1회 처리량 규칙

선별기 크기별 1회 처리량은 다음과 같다.

- 소형 선별기: `36상자`
- 중형 선별기: `72상자`
- 대형 선별기: `108상자`

기본 원칙:

- 중형은 소형의 2배 처리량을 가진다.
- 대형은 소형의 3배 처리량을 가진다.
- 1회 처리량을 초과하는 물량은 한 번에 처리하지 않는다.
- 남는 상자는 다음 선별 회차로 넘긴다.
- 1회 선별 중에는 처리 대상 상자를 한 박스씩 순차 선별한다.
- 처리 중인 상자는 이동, 결합, 적재 대상으로 선택할 수 없다.

## 18. 선별기 적재칸 규칙

- 선별에 사용하는 적재칸은 선별기가 설치된 현재 창고에 이미 정해져 있는 수확물 적재칸을 그대로 사용한다.
- 선별기 실행 전 그 적재칸들 중 일부를 `투입칸`과 `배출칸`으로 지정한다.
- 즉, 소형/중형/대형 선별기라도 어떤 창고에 배치했는지에 따라 사용할 수 있는 적재칸 수가 달라질 수 있다.
- 처리량과 적재칸 용량은 같은 개념으로 취급하지 않는다.
- 적재칸은 `보관 가능한 상자 수`, 처리량은 `1회에 선별 가능한 상자 수`로 구분한다.
- 적재칸 1칸은 `최대 36박스`까지 적재할 수 있다.
- 적재칸 1칸에 `36박스 초과 적재`는 허용하지 않는다.
- 선별 결과물을 담을 선택된 `배출칸` 용량이 부족하면 선별을 시작할 수 없다.
- 선별 작업은 이미 창고/토지 적재량 안에 들어온 수확물을 처리하므로, 별도 창고 kg 용량 증가로 보지 않는다.
- 선별 전후 총 kg는 같아야 하며, 작업 시작 판단은 선택된 `배출칸`에 결과 박스를 배치할 수 있는지 기준으로 한다.
- 소형 선별기는 `소창고 이상`에만 설치할 수 있다.
- 중형 선별기는 `중창고 이상`에만 설치할 수 있다.
- 대형 선별기는 `대창고 이상`에만 설치할 수 있다.

## 19. 선별기 인원 규칙

선별기는 배치 인원 조건을 만족해야 가동할 수 있다.

현재 기준:

- 소형: `최소 1명`, `권장 2명`
- 중형: `최소 2명`, `권장 3명`
- 대형: `최소 3명`, `권장 4명`

적용 방식:

- 최소 인원 미달이면 가동 불가
- 최소 인원 이상, 권장 인원 미달이면 가동 가능하지만 속도 감소
- 권장 인원 이상이면 정상 속도

## 20. 선별기 실행 규칙

- 선별은 버튼을 눌러 시작한다.
- 실행 전에 작업 대상 요약 모달을 따로 띄우지 않고 바로 실행한다.
- 실행 버튼이 비활성화되어 있으면 비활성 사유를 버튼 근처에 표시한다.
- 버튼을 누르면 선별기 애니메이션이 재생된다.
- 애니메이션이 재생되는 동안 처리 대상 상자를 한 박스씩 순차 선별한다.
- 소형 선별기는 1회 최대 `36상자`, 중형 선별기는 1회 최대 `72상자`, 대형 선별기는 1회 최대 `108상자`를 순차 처리한다.
- 처리 대상은 선택된 `투입칸` 순서 기준으로 잡는다.
- 각 상자는 선별 완료되는 순간 선별 전 박스를 빈 상자로 반환하고, 결과 박스를 선택된 `배출칸`에 반영한다.
- 한 입력 박스가 여러 급/다이 잔량으로 쪼개지면, 해당 박스 처리 완료 시 그 결과를 모두 반영한다.
- 결과 박스 반영과 잔량 합치기는 선택된 `배출칸` 범위 안에서만 처리한다.
- 애니메이션 중 아직 처리되지 않은 상자는 선별 전 상태로 남는다.
- 애니메이션이 끝난 시점에는 해당 회차에서 처리 가능한 상자가 모두 처리된 상태여야 한다.
- 현재 선별기 애니메이션 시간은 `20초`다.
- 작업 중에는 취소 버튼을 제공하지 않는다.
- 작업 중에는 저장을 막는다.
- 작업 중에는 현재 회차에 지정된 `투입칸`과 `배출칸`만 잠그고, 다른 적재칸은 별도 규칙이 없는 한 유지한다.
- 작업 완료 로그는 박스마다 남기지 않고 회차마다 하나만 남긴다.
- 예: `선별 완료: 후지 36박스 처리`

## 21. 선별기 자원 소모 규칙

- 선별 시 소모 자원은 `노동력`만 사용한다.
- `꼭지만 제거된 급 미정 박스` 선별은 `1차 품질 선별 + 2차 다이 선별`을 모두 포함하므로 노동력이 더 많이 든다.
- `부분선별까지 끝난 다이 미정 박스` 선별은 `2차 다이 선별`만 수행하므로 노동력이 더 적게 든다.
- 같은 이유로 선별 시간도 `부분선별 완료 박스` 쪽이 더 짧고, `꼭지만 제거된 박스` 쪽이 더 길다.
- 전기료, 연료, 포장 자재 같은 별도 소모는 현재 규칙에 포함하지 않는다.

## 22. 선별기 내구도 규칙

- 선별기 가동 시 내구도는 소모된다.
- 현재는 소형, 중형, 대형 모두 같은 내구도 소모 규칙을 적용한다.
- 현재 기준은 `선별 1회당 내구도 -1`이다.

## 23. 구현 점검 규칙

선별기 관련 구현을 수정할 때는 계산 규칙만 보지 않고 아래를 함께 확인한다.

- 상자 단위 선별/결과 반영 처리
- 같은 품종 제한
- 꼭지 제거 완료 여부 검사
- 선별기 칸 저장 처리
- 1회 처리량 제한
- 적재칸 36상자 제한
- 최소/권장 인원 적용
- 애니메이션 중 박스 단위 순차 처리
- 작업 중 저장 금지 및 적재칸 잠금
- 회차 단위 로그
- 노동력 차감
- 내구도 차감
