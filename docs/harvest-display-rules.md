# 수확물 표시 규칙

수확물 상세표시는 반드시 현재 작업 단계에 맞는 정보만 보여준다.

## 1. 기본 원칙

- 수확 직후와 꼭지제거 작업 단계에서는 `품질명`을 표시한다.
- 최종 선별기 선별 후에는 `품질명`과 `꼭지상태`를 표시하지 않는다.
- `급`이 아직 정해지지 않았으면 `급 미정`으로 표시한다.
- `다이`가 아직 정해지지 않았으면 `다이 미정`으로 표시한다.
- 잔량 박스는 해당 단계의 표시 뒤에 `· nkg 잔량`만 추가한다.
- 한 박스 상세표시에는 박스 수량을 붙이지 않는다.

## 2. 기본 수확 후

표시 구조:

- `과종 + 품종 + 품질명 + 급 미정 + 다이 미정 + 꼭지있음`

예시:

- `사과 후지 특상급 중하 급 미정 다이 미정 꼭지있음`
- `사과 후지 특상급 중하 급 미정 다이 미정 꼭지있음 · 7kg 잔량`

의미:

- 수확만 한 상태라 품질명은 표시한다.
- 아직 선별 전이라 급과 다이는 정해지지 않았다.
- 꼭지도 아직 붙어 있다.

## 3. 꼭지제거 작업 후

표시 구조:

- `과종 + 품종 + 품질명 + 급 미정 + 다이 미정 + 꼭지제거됨`

예시:

- `사과 후지 특상급 중하 급 미정 다이 미정 꼭지제거됨`
- `사과 후지 특상급 중하 급 미정 다이 미정 꼭지제거됨 · 7kg 잔량`

의미:

- 꼭지만 제거했기 때문에 품질명은 그대로 유지한다.
- 급과 다이는 아직 미정이다.
- 꼭지 상태만 `꼭지제거됨`으로 바뀐다.

## 4. 꼭지제거 + 부분선별 작업 후

표시 구조:

- `과종 + 품종 + 품질명 + 급 + 다이 미정 + 꼭지제거됨`

예시:

- `사과 후지 특상급 중하 A급 다이 미정 꼭지제거됨`
- `사과 후지 특상급 중하 A급 다이 미정 꼭지제거됨 · 7kg 잔량`
- `사과 후지 특상급 중하 가공품 다이 미정 꼭지제거됨`

의미:

- 꼭지를 제거하면서 1차로 `A급 / B급 / 가공품`까지 나뉜 상태다.
- 다이는 아직 선별기 전이라 미정이다.
- 품질명과 꼭지 상태는 계속 표시한다.

## 5. 선별기에서 선별 후

표시 구조:

- `과종 + 품종 + 급 + 다이`

예시:

- `사과 후지 A급 3다이`
- `사과 후지 A급 3다이 · 7kg 잔량`
- `사과 후지 B급 4다이`
- `사과 후지 가공품 10다이`
- `사과 후지 가공품 10다이 · 12kg 잔량`

의미:

- 최종 선별이 끝난 상태다.
- 실제 판매/보관 기준인 급과 다이만 표시한다.
- 최종 선별된 박스 상세에는 품질명, 꼭지상태, 박스 수량을 표시하지 않는다.
