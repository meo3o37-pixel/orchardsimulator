# 설계 작업 현황

갱신: 2026-11-19. 공유 작업본 기준이며 배포 완료 기록은 아님.

## 어디까지 했는가

- 재배구역·식재: 품종·대목 통합 선택, 배수로 굴착 폭 양옆 50cm의 예정 나무 제외와 식재줄 잘림 반영.
- 지주시설: 비계파이프 기본 최대 간격 6m, 비계·개별 지주·와이어 이미지 카드, 완료 버튼 상태 적용.
- 관수시설: 주관·점적호스 범례 및 표시 토글, 설치 방식 그림, 관수 방식·32mm 주관 이미지 카드 적용.
- 배수로: 세 종류 고정 규격·가격·배수 능력·막힘 차등, 자가 자재·삽 작업, 경계 배출구·연결 스냅·역순 그리기 정렬, 길이 게이지·경사·상태·제외 주수 카드 적용.
- 유공관: 식재 전 예정 열 자동 배치, 100/150mm 선택과 이미지, 보라색 표시, 자동·수동 연결 및 열별 연결 취소, 저장/연결 공통 판정 적용.
- 확정 현황·실시간: 배수로/유공관 공통 선 스타일 연결. 설계별 표시 토글 추가.

## 현재 마지막 수정

유공관 설계가 확정완료여도 자동 미리보기 데이터 때문에 시공 이동 버튼이 비활성화되던 문제를 수정했다. 저장된 설계와 같으면 ‘작업 탭에서 유공관 매설’을 사용할 수 있다.

## 다음 순서

1. **새 설계 탭 수정 전 유공관 마무리 검증부터**: 실제 게임에서 열 선택 → 자동/수동 연결 → 개별 취소 → 확정 → 탭 재진입 → 작업 탭 이동 → 자가/외주 시공까지 확인한다. UI 문법 검사만으로 저장·시공 완료를 단정하지 않는다.
2. 기존 테스트 갱신: orchardPipeLayout.test.mjs는 예전 자동 집수관 생성 전제로 실패한 항목이 있다. 새 ‘열 자동 배치 → 연결 버튼’ 흐름에 맞춰 고치고, 기존 나무 연결 테스트는 배수로 식재 여유거리 변경을 반영한다. pipeSystem.test.mjs의 일일 수분 보존 실패도 원인 재확인이 필요하다.
3. **다음 새 설계 작업 후보는 일반시설 설계**: 주차장·야적창고 → 시설·건물 배치 → 도로 → 전기 순으로 UI/설계 확정/실제 시공 연결을 점검하는 것을 권장한다. 사용자가 다음 대상을 확정한 것은 아니므로 작업 시작 시 요청 범위를 따른다.

## 남은 주의사항

- 기존 나무 주수와 설계 주수가 다를 때 자동 재배정하는 마이그레이션은 구현하지 않았다. 기존 위치 연결은 주수·품종 일치를 요구한다.
- 흙수로 도로 횡단 금지는 설계 저장 검증이다. 개별 약차의 실제 주행 차단 시뮬레이션까지 구현한 것은 아니다.
- 하경사 연결 요구에 맞춰 유공관 연결관의 깊이/구배 검증을 완화했다. 현실적인 수리·수문 계산 완성으로 설명하지 않는다.
- 최근접 연결/짧은 연결관 회귀 테스트와 배수로 테스트는 통과 기록이 있다. 전체 테스트·최근 전체 빌드·실제 게임 전체 동작 검증 완료 기록은 없다.
- 이번 작업 커밋·푸시는 수행하지 않았다. 다른 작업 및 민감한 런타임 파일이 섞여 있으므로 전체 스테이징 금지.
